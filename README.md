# Classification of Facial Images Over/Under an Age Threshold
## Overview
Age-restricted sales rely on staff judgement, which mystery-shopping studies show to be unreliable. This project investigates whether convolutional neural networks can classify facial images as above or below an age threshold, as an automated first-pass check. Two ImageNet-pretrained architectures, ResNet34 and DenseNet121, were fine-tuned on FairFace, a dataset balanced by race, gender and age; because FairFace provides only age-group labels, the threshold was set at 20 rather than 18. After removing infant, greyscale and heavily blurred images and downsampling over-represented age groups, models were trained in two phases: classification head first, then the final convolutional blocks. Evaluation prioritised the false positive rate (FPR), minors classified as adults, with results disaggregated by race, gender and age and Grad-CAM used for interpretability. DenseNet121 achieved higher accuracy (86% vs 83%), but ResNet34 a lower FPR (0.11 vs 0.19). Errors concentrated in age groups adjacent to the threshold, accuracy differed by up to 14 percentage points between racial groups, and both models produced high-confidence false positives, ruling out a confidence-based human-referral scheme. The hypothesis is partially supported: ResNet34 misclassifies minors less often than staff fail to check ID, but neither model approaches commercial systems or is suitable for deployment.
